Source Parts Inc. is a global leader in electronics manufacturing, specializing in PCB assembly, component sourcing, and complete product development. With offices in New York, Amsterdam, and Shenzhen, they provide world‑class manufacturing solutions that accelerate innovation for customers worldwide, emphasizing quality, reliability, and transparency.

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Source Parts Inc.: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
